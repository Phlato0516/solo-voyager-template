# 安全分享與發行

本分享版已另存為獨立私人儲存庫，使用全新的 Git 歷史，未沿用原站 Site ID 或原儲存庫歷史。原網站與原儲存庫仍保持原狀。

## 分享給朋友

1. 先完成 setup-sites.md 的獨立新帳號驗收，確認朋友能使用 Sites 並成功登入新站。
2. 確認素材及依賴授權、文件與限制後，由擁有者決定是否將「分享版儲存庫」改成 Public；目前尚未執行公開。
3. 可在 GitHub 開啟 Template repository，讓朋友建立自己的程式庫。這只複製程式，不建立 Sites、不搬移旅行資料，也不授予原網站存取權。目前尚未開啟此設定。
4. 私人分享則需另外明確授權受邀者。不要為了分享程式改變原旅行網站的權限。

## 後續維護

從原站更新功能時，只挑選程式與必要結構遷移；不可直接合併含原站 hosting 身分的維護分支。每次更新重新執行 test:template，並檢查沒有環境檔、備份、資料庫、照片附件或憑證。

## 公開發行門檻

- 乾淨內容檢查、範例解析、空白 SQL 遷移、既有程式測試及建置通過。
- 新帳號可取得 Sites 建站資格並完成獨立登入、D1／R2 與上傳驗收。
- 無關帳號不能讀取私人旅程；各角色與版本衝突通過真實環境測試。
- 確認支援範圍、限制、素材及依賴授權、資料備份與回復方式。

未驗證的項目不可寫成「一鍵架設成功」或「任何人都可使用」。本儲存庫沒有自動部署 workflow。
