# 分享與發行限制

本分享版使用獨立 Git 歷史，未附帶原站 Site ID、旅行資料、成員或照片附件。公開分享的是程式；原站與私人驗收站的存取政策不隨之變更。

## 實驗版狀態

擁有者已要求將分享版作為實驗版對外分享。多人跨帳號驗收因暫時無測試者而略過，標記為尚未驗證；這不代表權限測試通過。朋友帳號取得 Sites 資格及完整獨立架設流程也尚未驗證。其餘實測見 template-validation.md。

因此目前不能宣稱任何人皆可一鍵架設，或已完成多人正式環境驗收。使用者應先建立自己的私人 Site，以虛構資料驗證後再放入真實資料或邀請朋友。

## 朋友如何使用

1. 閱讀 README、setup-sites.md、LICENSE 及 THIRD_PARTY_NOTICES.md。
2. 取得分享版程式，於具備 Sites 工具的工作環境建立自己的全新私人 Site、D1 與 R2。
3. 使用平台新配發的 Site ID，切勿加入原站或其他人的 hosting 身分、憑證及資料。
4. 先用 examples 的虛構 JSON 測試，再自行完成不同帳號及成員角色驗證。
5. GitHub 複製程式不會自動建立網站、搬移資料或授予原網站存取權。GitHub Template repository 是可另行開啟的便利設定，本次未將它視為網站一鍵部署功能。

## 公開的內容與界線

Public 儲存庫的程式、文件及版本歷史（包含 GitHub 提交者資訊）可供他人查看及複製；改回 Private 無法收回別人已下載的副本。資料庫與附件沒有存入本儲存庫。MIT 授權僅適用於原創／新增部分，第三方聲明仍須保留。

公開前已對現有來源及可達歷史內容進行常見憑證及原站識別模式檢查。這不是完整秘密、素材權利或依賴授權稽核，也不是安全保證。

## 後續維護

從原站更新時只挑選程式與必要結構遷移，不直接合併含原站 hosting 身分的分支。每次更新執行 test:template，檢查沒有環境檔、正式備份、資料庫、照片附件或憑證。本儲存庫沒有自動部署 workflow。
