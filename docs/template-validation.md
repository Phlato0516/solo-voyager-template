# 分享版驗收紀錄

日期：2026-10-18。獨立私人驗收站已完成第 1 版發布。原站與分享版程式庫分開，沒有移入原站 Git 歷史、Site 身分、正式資料或附件。

## 使用者實際操作驗收更新（2026-10-18）

已透過使用者提供的畫面、匯出檔及必要的雲端唯讀檢查，補驗下列項目：

- 擁有者登入、建立測試旅程及雲端儲存。
- 旅程封面網址顯示；另一趟測試旅程實際上傳照片後有檔案紀錄且畫面正常顯示。
- 收藏地點儲存、分類與封面顯示；匯出檔含 20 個欄位，實際解析器接受並保留封面與裁切位置。
- 使用者回報收藏匯出檔重新匯入後沒有重複新增；此項以使用者確認為依據。
- 匯入 1 筆虛構航班及 1 筆虛構住宿，畫面正確顯示日期、時間與兩地時區。
- 每日行程顯示出發日 09:00 航班、15:00 入住，以及退房日 11:00 退房。同日抵達資訊整合在航班牌卡，跨日抵達才另建牌卡。
- 收藏加入候選地點並排入每日行程，封面正常顯示。
- 使用者拖曳產生 09:00–10:00 → 09:30–10:30 預覽並確認儲存；畫面顯示成功，雲端唯讀檢查亦確認 event 版本 2、時間 09:30–10:30。

仍未驗證：登出後重新登入的持久化、拖曳復原、不同帳號與角色的雲端存取、朋友帳號獨立架站資格。未將這些項目視為通過，也未改變網站或儲存庫的私人狀態。

## 尚未通過完整驗收的項目

- **瀏覽器測試工具**：仍缺少 Sites 指定的 control-browser；改由使用者操作並提供畫面補驗，已通過項目見上方更新。尚待補驗登出重新登入與操作復原。
- **R2 驗證範圍**：已由使用者實際上傳照片、確認畫面顯示，並核對雲端檔案紀錄；尚未取得實體 bucket ID、完整物件清單或完成備份還原驗證。
- **不同帳號**：沒有朋友／無關帳號的受授權測試工作階段，未執行雲端不同角色與未授權存取測試；不能以本機替身結果替代。
- **不同使用者架設資格**：此次是同一擁有者建立另一個獨立 Site，尚未證明朋友帳號可取得 Sites 工具或完成架設。
- **乾淨外部電腦安裝**：本環境安裝成功使用既有套件快取，未驗證無快取的外部網路／Mac 安裝。
- **授權與備份**：保留第三方聲明及 MIT，不代表完整依賴／素材授權稽核；此次未執行正式 D1／R2 完整備份還原。
- **外部 MCP**：沒有開放 MCP、外部寫入 API 或變更原站部署。

## 接續人工操作驗收

只在獨立私人驗收站使用虛構資料：

1. 以擁有者登入，確認旅程與收藏皆空。
2. 建立「分享版測試旅程」（2027-04-01–04-03）。
3. 在收藏頁匯入 examples/places.json，再次匯入確認重複處理及補齊規則，匯出後比對。
4. 在測試旅程匯入 examples/bookings.json，確認航班、住宿日期與每日行程連動。
5. 加入收藏至每日行程，編輯時間、切換檢視，確認原資料保留。
6. 上傳無個資的測試照片，重整及重新登入後確認資料、照片皆存在，並測試 JSON 匯出。
7. 另行授權指定朋友進入測試站後，測試管理者／編輯者／檢視者及無關帳號；不要開放原站權限。

本版仍保持私人。須補齊上述實測與發行檢查，再決定公開或開啟 Template repository；儲存庫與部署成功不能視為朋友架設驗收成功。
